## 1 引言

### 1.1 编写目的

本文档定义「会记 · AI 会议纪要助手」的功能需求、非功能需求、数据需求与验收标准，作为系统设计、编码、测试和验收的依据。

### 1.2 项目背景

会议是工程项目建设中传递信息、形成决策的主要场景。传统会议纪要依赖人工整理录音或速记，存在三个问题：

1. **耗时**：一场一小时的会议通常需要 1～2 小时整理；
2. **遗漏**：讨论中的决议、负责人和截止日期容易遗漏；
3. **不可检索**：纪要以文档形式散落，跨会议查询困难。

大语言模型具备摘要、信息抽取和自然语言问答能力，适合承担纪要整理工作。本项目面向单用户本地使用场景，构建一个轻量、可离线保存数据、仅在调用 AI 时联网的小型应用系统。

### 1.3 术语

| 术语 | 说明 |
| --- | --- |
| 会议记录原文 | 用户粘贴的速记、录音转写或手写整理文本 |
| 纪要 | 由摘要、决议、待办三部分组成的结构化会议成果 |
| 待办 | 从会议中提取的、可执行且有责任人的任务 |
| DeepSeek API | 本项目调用的大语言模型服务，使用 OpenAI 兼容接口 |
| BM25 类检索 | 基于关键词重合度挑选相关会议的轻量检索方法 |

## 2 项目概述

### 2.1 项目目标

构建一个本地 Web 应用，实现「录入会议 → AI 提炼纪要 → 跟踪待办 → 跨会议问答 → 导出 Word」的完整闭环，并保证：

- 无 AI Key 时，基础会议管理功能仍可使用；
- AI 调用失败时不丢失已有数据；
- 所有会议数据保存在本地 SQLite，不上传除 AI 提炼所需文本外的任何数据。

### 2.2 范围

**包含：**

- 会议的新建、查看、编辑、删除与搜索；
- 调用 DeepSeek 生成摘要、决议、待办；
- 待办的勾选、编辑、删除与逾期提示；
- 跨会议自然语言问答与来源标注；
- 问答历史记录；
- Word 格式纪要导出。

**不包含：**

- 用户注册、登录与多用户权限；
- 音频上传与语音转写（记录原文由用户提供）；
- 公网部署与移动端 App；
- 会议日程提醒、邮件通知；
- 与第三方日历、OA 系统的集成。

### 2.3 用户特征

目标用户为需要整理会议纪要的项目成员或管理者，具备基本浏览器操作能力，无需了解 AI 原理。系统为单用户本地工具，不区分角色。

### 2.4 运行环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11、Linux 或 macOS |
| Python | 3.10 及以上（实际验证 3.14.2） |
| 浏览器 | Chrome、Edge、Firefox 等现代浏览器（实际验证 Edge） |
| 网络 | 基础功能离线可用；AI 功能需访问 DeepSeek API |
| 数据库 | SQLite 3（Python 标准库自带） |

## 3 功能需求

### 3.1 功能清单

| 编号 | 功能 | 描述 | 优先级 | 验收要点 |
| --- | --- | --- | --- | --- |
| FR-01 | 会议录入 | 填写主题、日期、参会人、地点、记录原文并保存 | 高 | 必填项校验；保存后跳转详情页 |
| FR-02 | 会议管理 | 查看列表、详情，编辑、删除会议 | 高 | 删除会议时关联决议与待办级联删除 |
| FR-03 | 会议搜索 | 按主题、参会人、摘要、原文关键词搜索 | 中 | 关键词命中正确，空结果有提示 |
| FR-04 | AI 纪要提炼 | 从记录原文生成摘要、决议、待办 | 高 | 输出结构化结果并入库；失败有明确提示 |
| FR-05 | 待办跟踪 | 勾选完成、编辑内容/负责人/截止日期、删除 | 高 | 逾期高亮；重新提炼保留已完成状态 |
| FR-06 | 智能问答 | 跨会议检索并回答自然语言问题 | 中 | 回答标注来源会议；资料不足时明确说明 |
| FR-07 | Word 导出 | 导出含摘要、决议、待办表格、原文的 docx | 中 | 文档可正常打开，中文排版正确 |
| FR-08 | 问答历史 | 保存并展示最近 8 条提问 | 低 | 刷新后仍可查看 |

### 3.2 详细需求

**FR-01 会议录入**

- 用户填写会议主题（必填，≤120 字）、日期（必填，ISO 格式）、参会人（选填，≤300 字）、地点（选填，≤80 字）、记录原文（选填，≤60000 字）。
- 日期默认当天，可使用日期选择器。
- 保存后进入会议详情页，状态为「草稿」。

**FR-02 会议管理**

- 列表按会议日期倒序展示，显示主题、日期、参会人、状态、未完成待办数。
- 详情页展示摘要、决议、待办、记录原文。
- 删除操作需要二次确认；删除会议后，其决议、待办一并删除。

**FR-04 AI 纪要提炼**

- 仅当存在记录原文时可触发。
- 提炼结果包含：摘要（≤120 字）、决议数组、待办数组（内容、负责人、截止日期）。
- 决议与待办允许为空数组，但三者不能同时为空。
- 重新提炼时，若新待办与旧待办内容完全相同，保留其「已完成」状态。
- AI 服务不可用时，页面按钮禁用并提示配置方法；调用失败时保留原数据。

**FR-05 待办跟踪**

- 未完成待办排在已完成之前，并按截止日期升序。
- 截止日期早于当天且未完成的待办标记为「已逾期」。
- 待办支持行内编辑，内容不能为空，截止日期必须为合法日期或留空。

**FR-06 智能问答**

- 问题长度 ≤500 字。
- 系统先按关键词重合度选择最多 3 场相关会议，再交给模型回答。
- 回答必须使用已录入会议的信息，并在关键结论后标注【会议：标题（日期）】。
- 资料不足时应说明无法回答，而不是编造。

**FR-07 Word 导出**

- 导出文件命名格式：`YYYY-MM-DD_会议纪要_主题.docx`。
- 内容依次为：标题、元信息表、摘要、决议、待办表、记录原文、生成说明。
- 正文使用宋体，标题使用黑体，待办以表格呈现。

**FR-08 问答历史**

- 每次问答保存问题、回答、来源会议和创建时间。
- 页面展示最近 8 条，支持展开查看完整回答。

## 4 非功能需求

| 编号 | 类别 | 要求 |
| --- | --- | --- |
| NFR-01 | 性能 | 本地 CRUD 页面响应 < 500 ms；AI 提炼 < 60 s；单次问答 < 30 s |
| NFR-02 | 易用性 | 全中文界面；危险操作二次确认；AI 调用期间有加载状态 |
| NFR-03 | 可靠性 | AI 失败不影响已有数据；纪要写入使用事务；错误信息可理解 |
| NFR-04 | 安全性 | 默认仅监听 127.0.0.1；API Key 仅存服务端；.env 与数据库不提交 Git |
| NFR-05 | 兼容性 | Python 3.10+；现代浏览器；无需 Node.js 构建链 |
| NFR-06 | 可维护性 | 分层清晰；配置外置；自动化测试覆盖核心流程；文档完整 |
| NFR-07 | 隐私 | 会议原文仅在提炼与问答时发送给模型服务；本地数据不主动外传 |

## 5 数据需求

| 数据实体 | 主要字段 | 保存要求 |
| --- | --- | --- |
| 会议 | 主题、日期、参会人、地点、原文、摘要、状态 | 永久保存，用户可删除 |
| 决议 | 所属会议、内容、排序 | 随会议删除 |
| 待办 | 所属会议、内容、负责人、截止日期、完成状态 | 随会议删除；支持更新 |
| 问答记录 | 问题、回答、来源、时间 | 永久保存；页面展示最近 8 条 |

数据量假设：单用户场景，会议数量 < 1000，单场记录原文 ≤ 60000 字，数据库规模 < 100 MB。

## 6 约束与假设

1. 系统依赖 DeepSeek API 的可用性与网络连通性；不保证模型输出的绝对准确性。
2. 用户粘贴的会议记录应不含需要严格保密的敏感信息，或应先自行脱敏。
3. 系统为单用户工具，不提供并发写入控制与用户隔离。
4. 模型默认使用 `deepseek-flash`，可通过环境变量切换为账号可用的其他模型。
5. AI 输出需要人工复核，系统不将其作为正式决策依据。

## 7 用例说明

### UC-01 录入并提炼会议纪要

- **参与者**：项目成员
- **前置条件**：系统已启动，DeepSeek API Key 已配置
- **主流程**：
  1. 用户点击「新建会议」，填写主题、日期、参会人和记录原文；
  2. 系统校验必填项并保存会议；
  3. 用户进入详情页，点击「AI 提炼纪要」；
  4. 系统调用模型，解析并保存摘要、决议、待办；
  5. 页面展示提炼结果，状态变为「已提炼」。
- **异常流程**：
  - 必填项缺失：返回表单并提示；
  - API Key 未配置：按钮禁用并给出配置说明；
  - 模型超时或返回格式错误：提示错误，原会议数据保留。
- **后置条件**：会议拥有结构化纪要，可继续跟踪待办或导出。

### UC-02 待办管理

- 用户在详情页勾选待办，系统更新完成状态并刷新统计；
- 用户展开「编辑」，修改内容、负责人或截止日期；
- 用户删除待办，系统二次确认后移除；
- 逾期待办以红色边框和「已逾期」标签提示。

### UC-03 跨会议问答

- 用户进入「智能问答」，输入问题；
- 系统检索相关会议并调用模型；
- 页面展示回答与参考会议链接；
- 问答记录写入历史。

### UC-04 导出 Word

- 用户在详情页点击「导出 Word」；
- 系统生成 docx 并以附件下载；
- 文档包含摘要、决议、待办表格和原文。
