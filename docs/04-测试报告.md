# 测试报告

> 项目：会记 · AI 会议纪要助手　版本：v0.1.0　测试日期：2026-11-18

## 1 测试概述

### 1.1 测试目标

验证系统是否满足《需求规格说明书》中的功能与非功能要求，重点检查：

1. 会议与待办 CRUD 的正确性、校验与级联删除；
2. AI 纪要提炼在正常、异常与格式不稳定情况下的行为；
3. 智能问答的来源标注与历史记录；
4. Word 导出的内容完整性与文件可打开性；
5. 页面在真实浏览器中的可用性。

### 1.2 测试范围

| 范围 | 内容 |
| --- | --- |
| 单元测试 | JSON 解析、日期归一化、检索排序、AI 参数与截断、错误信息 |
| 接口/集成测试 | 会议、待办、问答、导出、健康检查路由 |
| AI 联调测试 | 使用真实 DeepSeek Key 完成提炼、问答、导出 |
| UI 验收 | Edge 无头浏览器访问主要页面并截图 |
| 不包含 | 压力测试、并发测试、安全渗透测试、多用户场景 |

## 2 测试策略

1. **测试与 AI 解耦**：通过 `FakeAIService` 注入固定输出，使 32 个自动化用例完全离线、可重复、不产生费用。
2. **AI 契约测试**：单独测试 JSON 解析对代码块、前后噪声、字段缺失、日期格式的容错。
3. **真实联调**：使用真实 Key 执行一次完整业务闭环，记录耗时与输出质量。
4. **UI 验收**：用真实浏览器渲染页面，检查布局、样式与交互状态。
5. **回归**：修复缺陷后重新运行全部自动化测试与截图。

## 7 遗留风险

1. **模型幻觉**：AI 仍可能把讨论误判为决议，或编造负责人；系统通过「只依据原文」提示词与人工复核降低风险，但无法完全消除。
2. **提示词注入**：会议原文若包含恶意指令，可能影响模型输出；当前未做内容过滤。
3. **长文本截断**：超过 60000 字的记录会被截断，可能遗漏末尾信息。
4. **单用户假设**：无登录与并发控制，不适合直接部署公网。
5. **网络依赖**：DeepSeek 服务不可用时 AI 功能不可用，基础功能不受影响。
6. **未做压力测试**：未验证大量会议与高并发下的性能。

## 8 测试结论

系统功能完整，核心流程可用；自动化测试全部通过，整体覆盖率 90%；真实 AI 联调在 6.7 s 内完成提炼，待办与相对日期解析准确；Word 导出内容完整；发现的 2 个产品缺陷均已修复。系统满足课程小型应用系统的验收要求，遗留风险已在文档中说明。
